# Premium suite design
Mode: Operate for all product surfaces; Experience for the gallery.
The user's binding direction is recognizable real-product UI, implemented directly in HTML. No alternate invented visual world is needed.
Canvas products use light editing surfaces, authentic floating/docked chrome, differentiated shape languages, populated collaborative scenes, and restrained brand accents.
Dashboards use product-specific navigation, dense data tables, provider management, routing or terminal layouts. Light management surfaces and dark monitoring/terminal surfaces reflect their distinct use scenes.
Tokens: 4px spacing rhythm, system UI text for native app conventions, tabular metrics, 1px separators, 8–12px panel radii, offset soft shadows for floating editor chrome. SVG icons use 1.7px consistent strokes.
Each file embeds its CSS, geometry, demo data and interaction code. Screenshot evidence determines verdicts, not file generation.
