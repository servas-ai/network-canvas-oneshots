# Product references

These implementations use original HTML/CSS/SVG. Product features and visual conventions were checked on 6 October 2026. Values, accounts and activity are illustrative. No source screenshots are embedded in the product HTML.

| Product | Primary reference | Visual guidance |
|---|---|---|
| Miro | https://miro.com/ | Light board, blue sharing controls, floating vertical tool rail, sticky notes, collaborators and comments. |
| FigJam | https://www.figma.com/figjam/ | Purple identity, pastel workshop sections, floating bottom tools and board outline. |
| Lucidchart | https://www.lucidchart.com/ | Orange identity, docked shapes, formatting ribbon, connectors and shape inspector. |
| Whimsical | https://whimsical.com/ | Purple mind maps, smooth branches, light cards and project details. |
| Mural | https://www.mural.co/ | Burgundy identity, facilitated board, timer, agenda and voting. |
| OpenCodex | https://github.com/lidge-jun/opencodex/blob/main/docs-site/src/content/docs/guides/web-dashboard.md | Account pools, provider management, delegation guidance and sidecars. |
| CPA Manager Plus | https://github.com/seakee/CPA-Manager-Plus | [Published dashboard](https://github.com/seakee/CPA-Manager-Plus/blob/main/img/dashboard.png): blue management UI, traffic, health matrix and token mix. |
| Magpie | https://github.com/yetone/magpie | [Published panel](https://github.com/yetone/magpie/blob/main/site/public/img/panel-light.png): agent-specific model and effort selection, profiles and routing groups. |
| EasyCLIProxyAPI | https://github.com/router-for-me/EasyCLIProxyAPI | [Published home](https://github.com/router-for-me/EasyCLIProxyAPI/blob/main/docs/screenshots/en/1.png): teal desktop management, runtime and protocol endpoints. |
| CLIProxy Quota Tray | https://github.com/ZYHUO/CLIProxy-Quota-Tray | [Published overview](https://github.com/ZYHUO/CLIProxy-Quota-Tray/blob/master/docs/screenshots/overview.png): dark monospace cost/status monitor and provider quota panels. |
| CC Switch | https://github.com/farion1231/cc-switch | [Published provider screen](https://github.com/farion1231/cc-switch/blob/main/assets/screenshots/main-en.png): blue identity, orange add action, agent tabs, provider rows. |
| 9Router | https://github.com/decolua/9router | Combos, provider fallback, clients and token compression. |
| Claude Code Router | https://github.com/musistudio/claude-code-router | Local gateway, model routing, transformers, request logs and retries. |
| CLIProxyAPI Usage | https://github.com/zhanglunet/cliproxyapi-usage-dashboard | Local SQLite analytics, account/model statistics and Codex quota windows. |
| Tokscale | https://github.com/junhoyeo/tokscale | Terminal analytics, annual contribution grid, model/cost/source breakdowns. |

The reference images for five dashboards were opened for visual comparison. The remaining product identities follow public product conventions and documented workflows. Exact fidelity to a particular release is not claimed. The Quota Tray's first macOS popover interpretation was rejected after comparison with its actual Windows/Linux dashboard.
